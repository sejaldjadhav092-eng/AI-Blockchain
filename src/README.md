# Source Code

## Purpose
This folder contains the source code for the Blockchain Based Academic Certificate Verification project.

## Main Functions
The source code is responsible for:
- Certificate registration
- Certificate verification
- Blockchain interaction
- Data validation
- User interaction
- Verification result generation

## Working
The application accepts certificate-related information and uses the blockchain record to verify its authenticity.

## Development
The source code is developed and tested during the internship project. Different modules may be added as the project progresses.

## Structure
Source files are organized according to their functionality to make the project easy to understand and maintain.
