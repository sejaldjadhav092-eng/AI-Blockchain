# Data

## Purpose
This folder contains the data used for the Blockchain Based Academic Certificate Verification project.

## Data Description
The data may include academic certificate details and other information required for certificate verification.

## Types of Data
- Certificate information
- Student details required for verification
- Institution information
- Certificate identification details
- Blockchain-related verification records

## Data Processing
The collected data may be cleaned, validated, and prepared before being used by the application.

## Data Security
Sensitive information should be handled carefully. Only the required information should be stored and used for verification.

## Usage
The data in this folder is used for testing, development, and verification purposes.
